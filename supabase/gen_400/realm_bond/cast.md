# 4.0 권역 인연 인물 설정

권역 이야기(rb_<권역>_2~5)에 나오는 새 인물의 설정을 모아 둔다. 권역마다 절 하나를 두고, 다른 작업자가 파도너울성·불씨들녘·잿빛그늘숲 절을 덧붙인다. 대본 파일(script_<권역>.md)의 「## 인물」에는 파서가 읽는 한 줄 소개만 둔다. 이 파일은 생성기가 읽지 않는다.

설정 틀은 canon.md §9와 같다: 종·성별·외견 나이·생김새·성격·말투·내력·버릇과 좋고 싫은 것·관계·네 편에 걸친 변화. 이름은 이름 사전(existing_names.json)·4.0 대본·보조 퀘스트와 겹치지 않음을 확인했다(11/26). 주인공의 성별·출신은 어느 인물의 말로도 정하지 않는다.

| 항목 | 내용 |
|---|---|
| 종 | 산 이(태어난 이, 사람), 산마을에서 나고 자람 |
| 성별·외견 나이 | 여 · 70대 중반 |
| 생김새 | 키가 작고 허리가 조금 굽었지만 어깨와 손이 다부지다. 마디 굵은 손에 굳은살이 박였고, 숯과 소금 일로 손등이 늘 거칠다. 흰머리를 땋아 머리 뒤에 둘둘 감아 올리고, 그 위에 털소 털로 짠 회색 털모자를 쓴다. 얼굴은 볕과 바람에 그을려 주름이 깊다. 털 망토를 두세 겹 껴입고, 손때 묻은 노간주나무 지팡이를 짚는다. 허리끈에 곳간 열쇠 꾸러미를 단다. |
| 눈에 띄는 것 | 지팡이 끝으로 무엇이든 가리키고 두드린다. 곳간에서 늘 쓰는 바닥에 금 간 찻그릇. |
| 성격 · 장점 | 셈이 빠르고 곳간을 한 톨도 허투루 쓰지 않는다. 남은 이들 몫을 산 이보다 먼저 챙긴다. 겉으로는 퉁명해도 손님 짐부터 들어 준다. |
| 성격 · 단점 | 고집이 세고 남의 사정을 묻기 전에 잔소리부터 한다. 걱정을 화로 낸다. 남에게 일을 시키는 것을 면구스러워해서 혼자 다 하려 들다 무릎을 다친다. |
| 두려움 | 곳간이 비어 마을이 겨울을 못 나는 것. 불러 줄 이 없는 데서 남은 이가 흐려지는 것. |
| 바라는 것 | 곳간이 차는 날 마을 사람 모두가 한 상에 둘러앉는 것. 해마다 그 상에서 부를 이름이 줄지 않는 것. |
| 말투 | 반말. 하게·해라를 섞는 산마을 노파 말씨(「~게」「~구먼」「~지」「~야」). 조사원은 처음에 「손님」, 3편부터는 이웃의 일을 맡기고, 5편에서는 식구로 대한다. 싸락은 「싸락이」로 부르고, 화가 나면 「이 미련한 것아」라고 한다. |
| 입버릇 | 「~하는 법이야」, 「됐네」 |
| 예시 대사 | 「손님 짐은 마을이 들어 주는 법이야. 거기 서서 버티지 말고 내려놓게.」 |
| 내력 | 돌마을 겨울 곳간을 마흔 해 넘게 맡아 왔다. 젊을 때는 털소를 치고 소금 호수에서 소금을 떴다. 곳간지기를 이어받은 뒤로는 해마다 겨울 들기 전 고기와 약초를 얼음 소금에 묻어 마을이 봄까지 버티게 한다. 남편과 형제를 먼저 보냈고, 그들을 배웅하며 「불러 줄 사람이 곁에 있어야 한다」는 생각을 굳혔다. |
| 버릇 | 그릇 수를 손가락을 접어 센다. 짐꾼들이 다 먹기 전에는 제 몫에 손대지 않는다. 걱정되면 깃발 문 아래 나가 눈을 맞으며 기다린다. |
| 좋아하는 것 | 볶은 보릿가루 경단을 수유차에 적셔 먹는 것. 굵은 얼음 소금. 벼락이 구운 파란 숯불. |
| 싫어하는 것 | 손님에게 일 시키기. 빈 소금 독. 혼자 무리하는 남은 이(특히 싸락). |
| 관계 | 싸락은 딸처럼 아끼며 가장 많이 혼낸다. 짐꾼들과 마을 사람들에게는 곳간 열쇠를 쥔 어른이다. 조사원은 처음에 손님으로 대하다가 이웃에게 맡길 일을 맡기고, 끝내 금 간 찻그릇을 내준다. |
| 네 편에 걸친 변화 | 2편: 손님은 일을 시키지 않는다는 예법을 고집하다 「이번 한 번」만 꺾는다. 3편: 무릎 때문에 이웃에게 일을 맡기고, 싸락 앞에서 처음으로 소리 내 운다. 4편: 남은 이들을 바람 속에 내보내 놓고 산 이들만 따뜻한 데서 잤다며 제 몫을 뉘우친다. 5편: 「한식구 짐은 세지 않는다」며 조사원의 그릇을 식구 그릇 사이에 놓는다. |

### 싸락

| 항목 | 내용 |
|---|---|
| 종 | 남은 이(망자). 살아서 열두 겨울, 죽은 뒤 열여덟 겨울을 짐꾼으로 지냈다. |
| 성별·외견 나이 | 여 · 30대 초반(죽던 해의 모습) |
| 생김새 | 키가 크고 어깨가 넓다. 짐을 오래 져서 등이 곧고 다리가 튼튼하다. 검은 머리를 짧게 잘라 털끈으로 질끈 묶었다. 광대와 볼이 붉고 웃으면 덧니 하나가 보인다. 털소 털 저고리에 무릎까지 오는 털 덧바지를 입고, 소매 끝은 늘 해어져 있다. 남은 이라 바람을 오래 맞으면 손끝·어깨·팔꿈치 가장자리가 김 서린 유리처럼 흐려지고, 불 곁에서는 다시 짙어진다. |
| 눈에 띄는 것 | 손때 묻은 나무 지게. 지게 다리에 짐길마다 칼로 판 홈이 줄지어 있다(4편부터 맨 아래 홈 하나는 조사원 몫). |
| 성격 · 장점 | 밝고 붙임성이 좋으며 제 처지를 웃음으로 넘긴다. 짐꾼 일에 자부심이 있고 남의 일을 거드는 데 망설임이 없다. 궁금한 것은 바로 묻는다(본토 이야기를 들을 때 그렇다). |
| 성격 · 단점 | 무리하는 버릇이 있다. 반쯤 빈 지게로 돌아오는 것을 부끄러워해 몸을 깎아 가며 버틴다. 걱정을 끼치기 싫어 힘든 것을 숨긴다. 남에게 짐을 맡겨 본 적이 없다. |
| 두려움 | 일을 못 하게 되어 마을에 짐만 되는 것. 불러 줄 이 없는 데서 흐려지는 것. |
| 바라는 것 | 봄까지 버텨 맡긴 지게를 돌려받는 것. 남은 이들이 바람 소리 없는 데서 쉬는 것. |
| 말투 | 밝은 해요체(「~요」「~네요」「~거든요」). 너와는 「어르신」, 조사원은 2편에서 「손님」, 3편부터 「{이름} 님」. 5편 이름 부르는 상에서만 조사원을 이름 그대로 부른다. 기쁘거나 놀라면 「아이고」. |
| 입버릇 | 「도로 붙어요」(형상이 다시 짙어진다는 뜻), 「반만 무거워요」 |
| 예시 대사 | 「바람을 오래 맞으면 이래요. 불 앞에 조금만 있으면 도로 붙어요.」 |
| 내력 | 돌마을 짐꾼 집안 딸. 열몇 살부터 설원과 등성이 짐길을 다녔고, 젊은 나이에 눈사태로 몸을 잃었다. 남은 이가 된 뒤에도 짐을 놓지 않았고, 산 이들이 거처와 화롯가를 내주는 대신 눈보라 속 짐을 나른다. 요즘 남은 이들이 예전보다 일찍 옅어지면서 싸락도 먼 길에서 쉽게 깎인다. |
| 버릇 | 지게 끈을 만지작거린다. 경단을 차에 푹 적셔 먹는다. 비늘을 꼬리부터 긁어야 한다면서 제 이마에 비늘을 묻힌다. |
| 좋아하는 것 | 뜨거운 맑은 국의 김. 짐길을 마치고 홈 하나 새기기. 털 장갑. |
| 싫어하는 것 | 천둥(움직이면 몸이 더 흐려짐). 빈 지게로 돌아오기. 불 앞에 가만히 앉아 있으라는 말. |
| 관계 | 너와는 혼나면서도 따르는 어르신이다. 짐꾼들과는 같은 남은 이 동무다. 조사원은 손님 → 이웃 → 처음으로 짐을 맡긴 벗 → 한식구. |
| 네 편에 걸친 변화 | 2편: 손님에게 일을 시키자며 너와를 꼬드기는 장난꾸러기. 3편: 사흘을 혼자 버티다가 이웃이 이름을 불러 주자 짐을 나눠 지는 법을 받아들인다. 4편: 처음으로 제 짐(지게)을 남에게 맡기고, 겨울 수를 세는 속내를 털어놓는다. 5편: 지게를 「이 집 짐」으로 돌리고 조사원 이름을 식구로 부른다. |

| 항목 | 내용 |
|---|---|
| 종 | 태어난 이(큰 몸집의 요괴, 부채 귀와 긴 코) |
| 성별·외견 나이 | 여 · 50대 |
| 생김새 | 사람 키의 두 배쯤 되는 큰 몸집에 몸이 둥글고 무겁다. 회색빛 살갗에 부채만 한 두 귀가 있고, 긴 코로 국자와 그릇을 말아 쥔다. 작고 검은 눈은 웃을 때 가늘어진다. 쪽빛 큰 두루마기 위에 기름 얼룩진 생무명 앞치마를 두르고, 귀 끝에 작은 놋고리를 단다. 맨발이고 발바닥이 넓적하다. |
| 눈에 띄는 것 | 기분이 귀에 다 드러난다. 기쁘면 펄럭이고, 걱정되면 축 늘어지고, 놀라면 하늘로 솟는다. 허리끈에 골목 문 패를 여럿 꿰어 찬다. |
| 성격 · 장점 | 느긋하고 정이 많다. 누구든 먼저 먹이고 본다. 탄 생선은 제가 먹고 성한 것을 남에게 준다. 처음 온 사람을 줄 앞으로 들일 만큼 손님 대접에 철저하다. |
| 성격 · 단점 | 혼자 다 떠안는다. 남에게 일을 시키지 못해 지치도록 일한다. 무엇을 건넬 때 쑥스러워 괜히 딴소리를 한다. 힘든 속을 남에게 보이지 않으려 한다. |
| 두려움 | 솥이 비어 줄 선 사람을 빈손으로 돌려보내는 것. 사십 년 전 저에게 밥을 내준 이의 흉내도 못 내게 되는 것. |
| 바라는 것 | 다리를 건너온 사람이 모두 이 골목에서 제자리를 찾는 것. 문설주에 새길 식구 표시가 늘어나는 것. |
| 말투 | 손님·조사원에게는 느긋한 해요체(「~지요」「~거예요」「어서」). 조사원은 2편 내내 「손님」, 3편 뒤로 「{이름} 님」(대본에서 이름을 부르는 첫 줄은 4편). 벼림에게는 다정한 반말(「벼림아」「~야」「~거다」). 놀라면 「아이고」「어머」「세상에」. |
| 입버릇 | 「그래야 제 마음이 편하지요」, 「아이고」 |
| 예시 대사 | 「손님이 낚아 온 건 손님 그릇에 제일 먼저 담을게요. 그래야 제 마음이 편하지요.」 |
| 내력 | 사십 년 전 성 밖 들녘 마을에 흉년이 들어 일곱 아치 돌다리를 건너왔다. 그날 나눔 부엌 뒷문에서 누군가 밥을 내주었고, 이튿날 국자를 쥐여 주었다. 그 뒤 부엌을 이어받아 저녁마다 새로 온 사람들을 먹인다. 해마다 달맞이성으로 오는 사람이 늘어 솥과 손이 모자라 간다. |
| 버릇 | 코로 사람 등을 살살 민다. 무엇을 건넨 뒤 귀를 접었다 편다. 큰 문 문턱에 털썩 주저앉아 쉰다. |
| 좋아하는 것 | 향신 국물, 뒷문 문지방에 앉아 수로의 물레방아 소리 듣기, 줄 끝 사람까지 그릇을 받아 가는 저녁. |
| 싫어하는 것 | 빈 솥, 남이 굶는 것, 칭찬 듣기(귀가 빨개짐). |
| 관계 | 벼림은 데려다 키우는 아이처럼 챙긴다. 골목 사람들에게는 큰 문의 어른이다. 조사원은 큰 문으로 들인 손님 → 골목 문 패를 준 이웃 → 뒷문의 벗 → 문을 두드리지 않는 한식구. |
| 네 편에 걸친 변화 | 2편: 손님에게 일을 안 시키려다 줄 선 아이 때문에 꺾인다. 3편: 쑥스러워하며 이웃에게 패를 건네고 벼림도 이웃으로 들인다. 4편: 처음으로 빈손으로 사람을 보낸 밤 벗 앞에서 울고, 사십 년 전 받은 국자를 떠올려 부엌을 혼자 짊어지지 않기로 한다. 5편: 문설주에 조사원 표시를 새기게 하고 「한식구는 문을 두드리지 않는다」고 말한다. |

## 파도너울성 (rb_pado_2~5)

중심은 본편 인물 물꼬(canon §9 그대로). 새로 만든 인물은 물꼬 배의 뱃사람과 선창 이웃 넷 — 모두 조연이라 짧게 둔다. 보조 퀘스트 인물 배 밥집 주인 덕파·찰랑 할미(data_side.NPC)를 빌려 쓰고, 덕파에게 「물꼬와 함께 첫 배 「쪽잠」을 탔던 사람」이라는 내력을 더했다(아래).

### 이 네 편에서 물꼬가 보이는 것
- 2 손님: 일손이 모자라 처음 보는 바깥누리 사람에게도 거리낌 없이 심부름을 시킨다. 「같이 줄을 잡아야 손님」. 밥은 제가 산다.
- 3 이웃: 위급할 때 먼저 물로 뛰어든다(숨이 가빠지지 않음 — 수중 생활). 제 집 말뚝을 내준다.
- 4 벗: 뱃길이 틀어진 뒤 「내가 틀리면 어쩌나」 싶어 쉬지 못했다. 첫 배 「쪽잠」 이야기를 처음 남에게 하고, 남 앞에서 처음 잠든다.
- 5 한식구: 「한 배를 타는 사람은 식구」. 노깃에 이름을 쓰게 하고 처음으로 이름을 부른다.
- 호칭: 주인공 「조사원」 → 5편 끝 「{이름}」. 덕파 「덕파 아저씨」, 찰랑 할미 「할머니」(해요체).

### 배 밥집 주인 덕파 — 더한 내력(보조 퀘스트 인물)
- 물꼬가 열여섯 살 때 첫 배 「쪽잠」에 함께 탔다가 물막이에 배가 깨지자 솥부터 끌어안았고, 물꼬가 덕파를 솥째 끌고 헤엄쳐 나왔다. 그 솥을 지금도 솥배에 건다. 물속에서 숨을 못 쉰다(물 위에 사는 태생 요괴 — 보조 퀘스트 설정과 어긋나지 않게 종은 적지 않음).
- 물꼬를 조카처럼 여겨 쉬게 하려고 주인공에게 낚시를 부탁한다. 「십 년에 한 번 하는 얘기」를 들었다는 데 슬쩍 샘낸다.

### 널다리 늙은 뱃사람
- 종·성별·나이: 물 아래에서 나고 자란 태생 요괴, 남, 외견 60대. 목덜미부터 귀밑까지 잿빛 비늘이 얇게 덮였고, 이마 주름이 깊다. 허리가 조금 굽었지만 어깨가 넓다. 소금기에 바랜 무명 홑옷, 맨발.
- 성격: 입이 무뚝뚝하고 잔소리가 많지만 손은 따뜻하다. 장점 — 일한 사람을 알아보고 챙긴다. 단점 — 처음 보는 사람을 일단 미덥지 않게 본다. 두려움 — 젊은 뱃사람들이 틀어진 뱃길에서 길을 잃는 것. 바람 — 은퇴 전에 물꼬가 한 번이라도 푹 쉬는 것.

- 관계: 물꼬의 배 사람. 덕파와 오랜 단골.

## 불씨들녘 (rb_bulssi_2~5)

중심은 본편 인물 쇠매·담금(7장 대본 그대로 — 쇠매는 화로 불씨에서 깨어난 화귀, 담금은 인간 장인). 새로 만든 인물은 화덕골 주민 노인 하나. 보조 퀘스트 인물 절구 아낙 매움이·유리 굽는 장인 해불(data_side.NPC)을 빌려 쓴다. data_quests.MAIN_NPCS의 쇠매·담금 소개(「쇠매가 요기를 팔려 함·담금이 문 닫지 못한다 함」)는 7장 대본과 거꾸로라 고쳐야 한다 — 대본은 7장대로 썼다.

### 이 네 편에서 쇠매·담금이 보이는 것
- 쇠매: 해요체, 주인공 「조사원님」 → 5편 끝 「{이름}」. 담금에게 반말. 성미가 급하고 잘 웃고 잘 운다. 불꽃이 감정과 함께 커지고(웃을 때 너울, 이름이 불릴 때 한 뼘씩), 손끝 불을 바늘처럼 모아 쇠에 글을 쓴다. 이름은 담금이 열네 살 풋내기 때 「쇠 다루는 집 아이니까」 지어 불렀다. 먹장어 땅김 훈제를 가장 좋아한다. 변화: 2 손님에게 미안해함 → 3 광맥을 손바닥으로 느끼고 목소리가 떨림 → 4 깨어난 날, 비밀을 맡긴 이를 벗이라 부름 → 5 불로 주인공 이름을 새김.
- 담금: 주인공에게 해요·합쇼 섞인 높임, 「조사원님」 → 5편 끝 「{이름} 씨」. 쇠매에게 반말. 셈이 밝고 장부를 놓지 않으며 농담은 마른 한마디. 변화: 2 「남이니까 부탁하는 거지. 식구한테는 부탁 안 하고 시키잖아」 → 3 광맥 단면을 손가락으로 몇 번이고 쓸며 「살아 있었어」 → 4 쇠매 몰래 선물을 준비하다 들킴 → 5 밤새 걸이를 벼리고 제 첫 망치를 물려줌.

### 화덕골 주민 노인
- 종·성별·나이: 인간, 남, 60대 후반. 볕에 그을린 얼굴에 주름이 깊고 앞니 하나가 빠졌다. 흙 묻은 무명 바지를 무릎까지 걷었고 허리에 낫집을 찬다.
- 성격: 느긋하고 눈썰미가 있다. 장점 — 남의 솜씨를 꼼꼼히 보고 좋으면 좋다고 말한다. 단점 — 투박한 것은 투박하다고 그 자리에서 말해 버린다. 두려움 — 농기구 고칠 데가 없어지는 것(7장 「이제 농기구는 어디서 고쳐야 할지」). 바람 — 올가을 고추를 제때 베는 것.

## 잿빛그늘숲 (rb_jaebit_2~5)

중심은 본편 인물 새움·옥산 할머니(8장 대본 그대로). 새로 만든 인물은 실오리와 고목 지기 넌출.

### 이 네 편에서 새움·옥산 할머니가 보이는 것
- 새움: 반말. 주인공을 청파 흉내로 「{이름} 님」(할머니가 「그 님은 누가 가르쳤느냐」), 5편 끝에 「식구한텐 님 안 붙이는 거야」 하며 「{이름}」. 나뭇결이 젖으면 짙어지고 겁나면 떨린다. 할머니를 돌보는 아이이면서 동생을 기다리는 아이. 변화: 2 제일 큰 과자를 손님에게 → 3 순번 패를 제 손으로 새기다 쪼갬 → 4 「동생이 영영 안 오면」 무서움을 털어놓고 「천천히 와도 돼. 나 여기 있을게」를 띄움 → 5 비밀을 지키느라 입이 아프다며 발을 구름.
- 옥산 할머니: 하오체, 주인공 「손님」 → 5편 「{이름} 님」. 손이 떨리고 기침하지만 농담이 빠르다(「쓴 걸 보니 잘 지었소」). 손님 자리는 마루 위. 새움이 밤마다 고목 아래 가는 것을 말없이 알아챈다. 넷째 가족패를 청하며 「짐을 지우려는 게 아니오」.

### 베 짜는 이웃 실오리
- 종·성별·나이: 억새 나루 억새밭에서 깨어난 화생, 여, 외견 30대 중반(깨어난 지는 스무 해 남짓). 억새 이삭처럼 희고 부스스한 머리칼이 바람이 없어도 사르르 흔들린다. 손등에 억새 잎맥 같은 가는 줄이 비친다. 키가 크고 마른 편, 쪽빛 물들인 베 저고리에 억새 비단 앞치마, 집 안에선 맨발.
- 성격: 상냥하고 말이 빠르며 남의 자랑을 잘 들어 준다. 장점 — 이웃 일을 제 일처럼 챙긴다(새움 고목 봐 주기). 단점 — 걱정을 웃음으로 덮다가 얼굴에 다 드러난다. 두려움 — 베틀을 놓고 달맞이성 목재 일에 나가게 되는 것, 그래서 화생의 터 순번이 또 비는 것. 바람 — 한 철이라도 베틀 앞에 앉아 있는 것, 자기처럼 숲에서 누가 깨어나는 것을 다시 보는 것.
- 말투: 해요체. 옥산 할머니를 「옥산 어르신」, 새움을 「새움아」(반말), 주인공을 처음엔 「옥산 어르신 댁 손님」, 그 뒤엔 이름 없이 해요체. 입버릇 「~거든요」. 예: 「새움이가 하도 자랑을 해서 얼굴 보기 전부터 아는 사람 같았어요.」 「이제 이웃이네요. 순번 날엔 우리 집에 와서 밥 먹고 가요.」
- 내력: 깨어났을 때 억새밭에 앉아 있던 것을 나루 베 짜는 집 노부부가 거두어 이름을 지어 주었다(실을 잘 감는다고). 노부부는 몇 해 전 일거리를 찾아 떠난 아들네로 옮겨 갔고, 실오리가 베틀과 고상가옥을 물려받았다. 억새 속심으로 짠 비단은 파도너울성 사람들이 좋아한다.
- 버릇·좋고 싫은 것: 북을 넘기며 혼잣말을 한다. 맨발로 마루를 뛴다. 좋아하는 것 — 비 그친 뒤 억새 냄새, 새움의 수다. 싫어하는 것 — 사공 자리가 빈 짐배.
- 관계: 새움네 이웃 — 새움이 약초를 캐러 가면 고목 아래를 봐 준다(「아줌마」라 불림). 우산 짓는 집(보조 퀘스트 기름보)과 같은 터 순번.
- 네 편의 변화: 3편 — 비단을 못 팔아 근심하던 얼굴에서, 주인공이 팔아 온 값을 쥐고 「한 철은 베틀 앞에 앉아 있을 수 있겠어요」 → 순번 빈 날을 주인공 날로 받아들이고 「이웃」이라 부른다. 4·5편엔 나오지 않는다(5편 가족패 장면은 집안 일이라). 뒤에 쓸 때는 순번 날 밥을 차려 주는 이웃으로.
