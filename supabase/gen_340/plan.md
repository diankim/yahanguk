- 직업 일곱: 호위 무사(방패·수호)·월궁 사수·퇴마관·의무관·봉인술사·암영 검객·조련사.
- 무기 갈래 셋, 직업 태그로만 나뉨: 근접(호위·암영) 35자루 · 원거리(사수·조련사) 34 · 술법(퇴마·봉인·의무) 34. 단계 1~8.
- 단계마다 수치 갈래 넷이 있음: 기본(피해 +%)·묵직(위력↑·이목 +30)·예리(치명타 +%)·소리 없음(회피·이목 −30). 이름은 수치 갈래마다 형태가 대체로 같음:
  - 근접: 기본 = 환도·장창·언월도·대도·참월도 / 묵직 = 철퇴·대부·철편·금강저 / 예리 = 단도·장검·쌍검·신검 / 소리 없음 = 비수·단검·소도·귀도
  - 원거리: 기본 = 단궁·장궁 / 묵직 = 쇠뇌·대노 / 예리 = 각궁·신궁 / 소리 없음 = 소궁·취관
  - 술법: 기본 = 방울·법경·법륜 / 묵직 = 금강령·법륜·종 / 예리 = 산가지·나경·산반·신산 / 소리 없음 = 부채·향로·등롱·법등
- 생활 효과가 붙은 무기는 명소 무기 여섯뿐(명석 참명도·명목 흑단궁·명초 법등과 등불 서린 셋, 명소 캐기 「…의 정」 +10%). 비장고 확률(mz_soil_pct)은 무기에 없고 방어구·관모·탈·신·노리개에만 있음 → 방어구는 공용이라 그대로.
- 지금 장착 무기와 직업(운영진 빼고): 암영 예리 7·기본 5 / 호위 예리 2·환도 1·묵직 1 / 퇴마 방울 4·기본 3·묵직 1·예리 1·명소 1 / 의무 소리 없음 3·기본 2·예리 2·묵직 1·명소 1·결계 부채 1 / 사수 기본 2·예리 2 / 봉인 묵직 2·예리 1·결계 부채 1 / 조련사 예리 1·소리 없음 1. → 같은 갈래 안에서 수치 갈래를 골라 쓰는 사람이 많음. 직업마다 수치 갈래 하나만 남기면 빌드 고르는 맛이 사라짐.
- 직업 바꾸기: 환골탈태 서첩(직업·소속, 거래 불가) — 세력 비고 2등급·공훈 300만. 세심단(능력치만) — 얻는 곳 없음. 서첩을 쓰면 능력치 포인트가 돌려받는 칸으로 돌아감(자동 배치 없음).

## 3. 무기를 직업별로 나누기

### 원칙
- 무기는 직업마다 고유 형태(이름) — 내 직업 무기만 낌. 방어구·장신구·생활 도구는 그대로 공용.
- 명소 무기 여섯(명소 캐기 덤)은 모든 직업이 낌. 다만 피해는 「그 역할 무기를 들었을 때만」 규칙이 있어 다른 역할이 들면 싸움 힘은 약함 — 캐기용.
- 수치 갈래(기본·묵직·예리·소리 없음)는 직업 안에서 고르게 남김 → 빌드 고르는 맛 유지.

- 수치·값은 지금 단계 공식 그대로, 이름만 직업 형태로. 이름은 겹침 검사(ref) 거침.

## 4. 장비 세트

칭호 묶음·퀵슬롯과 같은 틀.
- 표 world_gear_sets(owner_id, n, name ≤12자, items jsonb {칸: 물품 id}, updated_at) — RLS·직접 읽기 없음, 캐릭터 정리 대상.
- 칸 수 [결정 필요]: 6칸 고정 [추천] / 처음 3칸 + 칭호 묶음처럼 해금.
- 담는 칸: 전투 여덟(무기·방어구·관모·신·노리개·호신부·탈) + 생활 셋(채집·탐사·낚시) — 「채집 세트」(명소 장비)와 「싸움 세트」를 오가는 데 가장 쓸모 있음.
- RPC world_gear_set_save(n, name)(지금 낀 것 그대로) · world_gear_set_apply(n) · world_gear_set_rename · world_gear_set_clear · 목록은 world_inventory_state에 실어 보냄(요청 추가 없음).
- 바꿔 끼기 규칙: 한 처리 안에서 칸마다 world_equip_item 조건(레벨·직업·능력치) 검사. 없거나 못 끼는 칸은 건너뛰고 응답에 칸별 까닭. 저장한 물품이 없으면 짝(보통↔우수품, hq.js pairOf와 같은 규칙)으로 대신. 세트에 빈 칸이면 그 칸은 건드리지 않음. 전투·원정·이동·자율 중엔 장착과 같이 막힘.
- 화면(모바일 우선):
  - 가방 › 소지품 위 한 줄: 「장비 세트 · 지금: 싸움」 + 세트 칩(휴대폰 2열, 가로 스크롤 없음) — 누르면 확인 없이 바로 바꿔 끼기, 길게 누르거나 「⋯」로 덮어쓰기·이름 바꾸기·지우기.
  - 가방 › 장비: 세트 칸(카드) — 세트마다 칸별 물품 아이콘·「지금 낀 것과 다른 칸」 금빛 표시·못 끼는 칸 빨강. 휴대폰은 세트 하나씩 펼치는 접는 칸.
  - 상태판 퀵 버튼은 넣지 않음 [추천] (자리 부족).

## 5. 직업 바꾸기 (직변권)·세심단
