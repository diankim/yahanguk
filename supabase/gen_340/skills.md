# 3.4.0 세 직업 기술 초안 (2026-11-19 — 수치는 시뮬 전 첫 값)

틀은 기존 직업과 같음: 기본 기술 9(3·8·13·18·24·30·36·43·50단계, 그 계열 분야에서만 붙는 수치) + 택일 4쌍(13·24·30·43단계, ①/② 두 갈래 — 의무관의 침술/처방처럼) + 숙달 1(50단계) = 계열마다 18. 협동 기술 4(전투 숙련 3·8·18·36). 현장 기술 1·원정 기술 1.

새 효과 키 둘: `shield`(보호막 — 받는 피해를 먼저 깎음, world_cb_mitigate 순서에 이미 「보호막」 자리 있음) · `leech_pct`(준 피해의 %를 체력으로). 보호막 세기 덤 `shield_pct`.

## 1. 혈기사(血騎士) — 계열 「혈투」(`bloodcraft`)

- 기본 능력치(합 30): 힘 9·체질 8·의지 4·나머지 3 (민첩·감각·영성).
- 서첩 자동 배치 순서: 힘 → 체질 → 의지.
- 직업 효과: 근접 피흡 8%(한 방에 체력 6까지) · 받는 피해 −6% · 이목 +50 · 공격력 ×0.95.
- 갈래 상성: 거괴·갑각.
- 현장 기술 「피 갑주」: 체력 15를 깎아 보호막 30을 3턴(기력 20). 다 깨지면 깎은 체력의 절반을 돌려받음. 비무 효과 kind `shield`.
- 원정 기술 「베어 버티기」: 싸움마다 25%로 그 싸움에서 받은 피해의 절반을 회복.

|---|---|---|
| 3 | 피 맛 | 근접 피해 +4% · 피흡 +1%p |
| 8 | 거친 숨 | 근접 피해 +12%, 거괴·갑각 요괴에게 +12% 더 |
| 13 | 굳은 살 | 받는 피해 −3% |
| 18 | 피 돌리기 | 피흡 +1%p · 회복량 +3% |
| 24 | 쇠 근육 | 받는 피해 −3% · 근접 피해 +2% |
| 30 | 흘린 만큼 | 피흡 +1%p |
| 36 | 붉은 갑주 | 보호막 세기 +6% · 받는 피해 −2% |
| 43 | 핏줄 단련 | 회복량 +5% · 피흡 +1%p |
| 50 | 혈기 일체 | 받는 피해 −3% · 근접 피해 +3% |

| 50 숙달 | **혈해(血海)** — 피흡 상한(한 방 6)이 10으로, 피 갑주를 쓸 때 체력을 깎지 않음 | (숙달은 하나) |

## 2. 진법가(陣法家) — 계열 「진법」(`formation`)

- 기본 능력치: 의지 9·영성 7·감각 5·나머지 3.
- 자동 배치: 의지 → 영성 → 감각.
- 직업 효과: 보호막 세기 +15% · 회복량 −10%(의무관과 반대) · 정신 손실 −5%.
- 갈래 상성: 금주·수귀.
- 현장 기술 「산가지 진」: 3턴 받는 피해 −35%, 끝날 때 남은 턴이 있든 없든 체력 +10(영력 25). 비무 kind `shield`.
- 원정 기술 「길흉 셈」: 회차마다 30%로 그 회차 받는 피해 −30%·침식 −1.
- 기존 「결계」 기술(퇴마 결계·청정결계)과 겹치지 않게 이름은 진·방위·땅 쪽 말.

|---|---|---|
| 3 | 산가지 놓기 | 술법 피해 +3% · 보호막 세기 +3% |
| 8 | 방위 읽기 | 술법 피해 +14%, 금주·수귀 요괴에게 +12% 더 |
| 13 | 팔괘 셈 | 보호막 세기 +4% |
| 18 | 명당 잡기 | 받는 피해 −3% · 정신 손실 −5% |
| 24 | 터 다지기 | 보호막 세기 +4% · 회복량 +2% |
| 30 | 구궁 셈 | 보호막 세기 +5% |

| 43 | 천지 방위 | 보호막 세기 +6% |
| 50 | 진법 대성 | 보호막 세기 +5% · 술법 피해 +3% |

| 43 | **무너지지 않는 진** — 동료가 쓰러질 피해를 받으면 한 전투에 한 번 보호막 25로 막음 | **판 뒤집기** — 수법 피해를 막아 낸 라운드 뒤 모두 다음 공격 +20% |

## 3. 여명 창객(黎明槍客) — 계열 「창술」(`spear`)

- 기본 능력치: 힘 8·민첩 7·체질 5·감각 4·나머지 3.
- 자동 배치: 힘 → 민첩 → 감각.
- 직업 효과: 근접 공격력 ×1.12 · 이어 찌르기(같은 대상을 연달아 치면 +6%씩, 셋까지 — 방어·물품·이동하면 끊김) · 현장 토벌 첫 턴 선제(요괴보다 먼저 한 번 찌름).
- 맵 보스(값귀·백야·무용담): 공격이 **이웃 칸 요괴·과녁까지 닿음**(지금 「제 칸에서만」 규칙을 창객만 한 칸 늘림).
- 갈래 상성: 비금·천상.
- 현장 기술 「관통 찌르기」: 근접 ×1.6·방어 절반 무시(기력 20). 비무 kind `pierce`(있는 것).
- 원정 기술 「새벽 돌파」: 싸움마다 30%로 첫 합을 먼저 쳐 승률 +10%p.

## 4. 기여도·혼자 도전·칭호

- 기여도: 혈기사가 동료에게 둘러 준 보호막이 막은 피해 → 「버팀」. 진법가의 보호막이 막은 피해 → 「치유」, 피해 감소로 줄인 몫은 지금 규칙(줄인 몫 절반 → 버팀). 피흡·자기 보호막은 셈 밖.
- 혼자 도전 보정(world_solo_aid·mukjeok.solo): 시뮬로 정함(정석 플레이 혼자 2~3/10).
- 칭호: 계열마다 ct_<계열>_15·35·50, 「…의 길」(공개) + 숨김 하나씩 — 혈투의 길·진법의 길·창술의 길.
