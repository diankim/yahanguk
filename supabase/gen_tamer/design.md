## 0. 월궁 사수와 같은 점·다른 점 (설계의 중심)

조련사는 월궁 사수와 **같은 원거리 계열**(활·쇠뇌·취관, 탄 소모, 민첩·감각 피해 계수)이다. 차이는 「혼자 쏘는 사수」와 「짝과 함께 사냥하는 사람」이다. 월궁은 화살 한 대의 질(급소·표식·치명타·몸놀림)로, 조련사는 화살 + 동무의 덧붙는 한 번(물기·막아서기·쪼기·홀리기)으로 싸운다.

| 항목 | 월궁 사수 (scout) | 조련사 (tamer) | 근거 |
|---|---|---|---|
| 무기 | 활·쇠뇌·취관 | **같음** [확정] | 원거리 태그를 둘이 함께 씀 |
| 피해 계수 | 민첩 0.6·감각 0.45 | **같음** [확정] | world_combat_stats 그대로 |
| 탄 소모 | 한 발 하나, 없으면 절반 | **같음** [확정] (동무 공격은 탄을 안 씀) | |
| 기본 능력치 | 근력4·민첩8·체질4·감각8·의지3·영성3 | 근력4·**민첩7**·**체질5**·감각8·의지3·영성3 [확정 방식·제안 값] | 월궁 바탕에서 민첩 한 점을 체질로 — 동무와 붙어 다니며 조금 더 버팀 |
| 직업 효과 | 원거리 피해 +8%·원거리 치명타 +4·회피 +6·도주 +15 | **없음**(대신 동무 짝) [제안] | 월궁의 덤이 「화살의 질」이라면 조련사의 덤은 전부 동무에게 몰아 둠 — 겹치지 않게 |
| 기민(회피·도주·숨기 상한 근거) | 민첩+감각 16 | 민첩+감각 15 | 한 점 옮긴 만큼 조금 덜 피함 |
| 현장 기술 | 급소 사격(×1.4·표식 세 번) | **휘파람**(원거리 ×1.2 + 동무 동작이 반드시 터지고 동무 피해 ×2) [제안] | 월궁=다음 화살 강화 / 조련사=그 턴 동무 강화 |
| 매 턴의 덤 | 없음(표식 걸린 동안만) | **동무가 내 차례에 덧붙어 한 번** [확정] | 친밀도로만 힘, 등급 무관 [확정] |
| 유리한 갈래 | 비금·은형 | **군충·은형** [확정] — 은형을 함께 | |
| 덜 듣는 갈래 | 갑각·영귀 | 갑각·영귀(화살) — 단 동무 묶음에 따라 갑각·영귀에도 동무는 들음 | 동무 공격은 묶음마다 근접·원거리·술법 배율을 따로 받음(§4) |
| 협동 기술 | 약점 표시·길 터주기·연막·추격 신호 | 넷 모두 **동무를 거침** [확정](§5.3) | |
| 원정 기술 | 선제 사격(싸움마다 30% 승률 +12%p) | **동무의 코**(발견 +, 싸움 승률 덤 작게) [확정 방향·제안 값] | 「원정 발견 덤」 |
| 별채·동무 | 효과 없음 | **친밀도 덤**(돌보기 ×1.5, 이긴 싸움마다 +1) [확정 방향·제안 값] | 친밀도가 곧 힘이므로 기르는 길이 필요 |
| 혼자 도전 보정 | 귀허 −25/−46 · 결전 −47 | 처음엔 월궁과 같은 값에서 시작, 시뮬로 맞춤 [제안] | §6 |
| 어울리는 사람 | 멀리서 정확히 쏘는 사람 | 짝을 기르고 함께 싸우는 사람 | |

한 줄로: **월궁은 「쏘는 사람의 기술」, 조련사는 「기르는 사람의 짝」.** 화살 쪽 수치(원거리 피해·치명타·회피)는 월궁이 늘 앞서고, 조련사는 동무 친밀도를 채울수록 월궁을 따라잡는다(가득 찬 동무에서 같은 성적을 목표로 함, §6).

## 2. 능력치·직업 효과·무기·시작 장비

### 2.1 기본 능력치 world_job_base(합 30)

| | 근력 | 민첩 | 체질 | 감각 | 의지 | 영성 |
|---|---|---|---|---|---|---|
| 월궁 사수 | 4 | 8 | 4 | 8 | 3 | 3 |
| **조련사 [제안]** | 4 | **7** | **5** | 8 | 3 | 3 |

- 방식은 [확정](월궁 바탕에서 한 점 옮김). 11/5 메모의 예 「민첩7·감각8·체질6」은 합이 31이 되어(체질 4→6) 한 점이 아니라 두 점이므로, 합 30을 지키는 「체질5」로 적었다(결정 ②).
- 감각을 그대로 두는 까닭: 원거리 피해 계수(감각 0.45)와 치명타(감각×0.4)가 함께 걸려 있어, 감각을 깎으면 화살 쪽이 두 번 깎인다. 민첩은 피해 계수 0.6과 기민·이목에만 걸린다.
- 결과: 이목 = 30 + 체질×0.8 − 민첩×0.4 → 월궁 29.6 / 조련사 31.2(거의 같음). 기민 16 → 15.

| 키 | 월궁 | 조련사 [제안] |
|---|---|---|
| ranged_pct | 8 | 0 |
| 그 밖 | 0 | 0 |

## 3. 유리한 갈래 — world_monster_kinds 「한 직업 → 여러 직업」

지금 world_monster_kinds.job_key는 text 하나(비금 scout·은형 scout·군충 null 등)이다. 은형을 월궁·조련사가 함께 가지려면 배열로 바꾼다 [확정]. 앞으로 직업이 늘어도 같은 구조.

### 3.1 바꾸는 안

| 단계 | 내용 |
|---|---|
| 표 | `job_keys text[] not null default '{}'` 추가 → 기존 job_key로 채움 → 은형 `{scout,tamer}`, 군충 `{tamer}` → job_key 열 삭제(같은 배포에서, 부르는 함수를 모두 고친 뒤) |
| 판정 도우미 | `world_kind_job_ok(p_kind, p_job) → boolean` 하나(인라인되게 SQL)를 두고 모든 곳이 이것만 부름 |
| gamedata | `kindJobs: {bird:['scout'], shadow:['scout','tamer'], swarm:['tamer'], …}` 추가(tools/gamedata/gen.py, JOB_KEYS에 tamer) |

### 3.2 job_key를 읽는 곳 전부 (복제본 함수 본문 검색 결과)

| 함수·파일 | 지금 | 바꿈 |

### 3.3 군충 원거리 0.9 문제

- 군충은 근접 1.25·원거리 0.9·술법 1.1이다. 조련사의 화살은 군충에 0.9×1.2 = **1.08**이라 「유리한 갈래」인데도 다른 갈래 평균과 비슷하다.
- 동무 공격은 묶음마다 공격 방식을 따로 받는다(§4.2: 지키기·물기 근접, 쪼기 원거리, 홀리기 술법). 그래서 지키기·물기 동무면 군충에 1.25×1.2 = **1.5**, 홀리기면 1.1×1.2 = 1.32.
- [확정] 「동무 공격에 근접 배율을 받게 할지 시뮬로 정함」에 대한 제안: 묶음별 방식을 따르는 안(위)을 기본으로 하고, 시뮬에서 군충 상대 조련사 성적이 비금 상대 월궁보다 10% 넘게 처지면 「군충만은 동무 공격이 근접 배율」 예외를 둔다(결정 ⑤).
- 은형 두 직업: 은형은 원거리 0.9 → 화살은 둘 다 1.08. 월궁은 원거리 +8%·치명타로, 조련사는 물기 동무(근접 1.1×1.2=1.32)로 차이가 난다. §6에서 확인.

## 6. 밸런스 계획

### 6.1 목표 (CLAUDE.md §3.5·§10)

| 싸움 | 목표 |
|---|---|
| 귀허의 주인 | 정석 플레이로 넷 10/10·둘 5/10·혼자 2~3/10 |
| 10장 결전 | 혼자 약 3~4/10·둘 5~8/10 |
| 현장 | 같은 레벨 일반·정예·우두머리 승률·남는 체력·턴 수가 월궁 ±10% |
| 원정 | 시간당 경험치·전·전리품이 월궁 ±10%(발견 덤으로 채집 쪽은 조금 앞서도 됨) |

### 6.2 방법

- 시뮬은 **로컬 복제 DB에서만**(운영에서 돌리면 캐릭터 행을 잠가 시간 초과). 복제본 스크립트는 세션 작업 공간 replica/(build.sh)로 다시 만든다.
- 기존 시뮬 도구(세션 작업 공간 jobsim.py·fitsim.js·sim/)의 직업 목록에 tamer를 더해 같은 조건(협동 기술·6단계 장비 한 벌·정석 행동)으로 돌린다.
- 친밀도 0·100·300 세 경우 × 묶음 넷을 모두 돈다. **목표 성적은 친밀도 300 기준**, 친밀도 0에서는 월궁의 80% 안팎이면 된다(처음 며칠은 약하고, 기르면 따라잡음).
- 날씨·시간대로 판마다 크게 흔들리므로(1.0.1b 기록) 여러 묶음을 합쳐 본다.

### 6.3 은형 두 직업 차이 확인

| 비교 | 볼 것 |
|---|---|
| 은형 상대 월궁 vs 조련사(물기·친밀도 300) | 승률·턴 수 차이 10% 안 |
| 은형 상대 조련사 묶음 넷 | 물기가 가장 낫고(근접 1.1), 쪼기(원거리 0.9)가 가장 처지는지 — 묶음 고르는 의미가 남는지 |
| 군충 상대 조련사 vs 비금 상대 월궁 | §3.3 예외(근접 배율)가 필요한지 |

### 6.4 혼자 도전 보정 world_solo_aid [제안 — 시뮬 전 첫 값]

| | solo_dmg | solo_guard | final_dmg |
|---|---|---|---|
| 월궁 사수(지금) | −25 | −46 | −47 |
| **조련사 첫 값** | −30 | −46 | −47 |

- 동무 덧공격이 혼자일 때 고스란히 남으므로 귀허 주는 피해를 월궁보다 5 더 깎은 값에서 시작하고 시뮬로 맞춘다. 결전은 공격력 기준으로 체력이 맞춰지므로(§10) 동무 몫이 체력 계산에 안 들어가 그만큼 유리 → final_dmg도 시뮬 뒤 조정.
- 귀허·결전 보스 체력이 「참가자 공격력 합」으로 정해지는데 동무 피해는 공격력에 안 들어간다. **동무 몫을 보스 체력 계산에 넣을지**(attack_raw × (1+동무 기대 배율)) 결정 ⑨ — 넣으면 공정하지만 동무를 기른 보람이 보스전에서 사라짐.

## 8. 사용자에게 정해 달라고 할 것

1. **동무가 사람을 따르는 까닭 설정**(script.md 끝 「설정 정리」): 「밤의 작은 것들은 요기를 머금고 이름 없이 태어나 갈래로 불린다 → 이름을 지어 부르면 명줄 한 가닥 → 그 목소리를 붙들려고 따른다 → 오래 안 부르면 다시 갈래로 돌아간다 → 동무는 이름을 지어 준 사람의 이름을 기억한다」를 canon.md에 넣어도 되는지.
2. 기본 능력치: 민첩7·감각8·**체질5**(합 30, 한 점)로 할지, 메모 예처럼 체질6(합 31)으로 할지.
3. 첫 동무: 생성 화면에서 넷 중 고르기(인자 p_pet) vs 귀속 「조련사의 바구니」. 넷 종류(누렁 강아지·얼룩 고양이·참새·무당벌레)도.
4. 유리한 갈래 표시(lore.js good)를 gamedata kindJobs에서 저절로 만들지(한 곳) — 기존 여섯 직업 글도 함께 바뀜.
5. 군충 0.9 문제: 묶음별 공격 방식(지키기·물기 근접, 쪼기 원거리, 홀리기 술법)을 기본으로, 시뮬 결과에 따라 「군충만 근접 배율」 예외를 둘지.
6. 동무가 조련사의 **모든 차례**(방어·물품 포함)에 덧붙을지, 공격 차례에만일지.
7. 길 위 돌보기(데리고 다니는 동무 돌보기)를 **모든 직업**에 열지, 조련사만 열지.
8. 비무 현장 기술 종류: 새 kind 'pet' vs 기존 'focus'로 대신.
9. 귀허·결전 보스 체력 계산에 동무 몫을 넣을지.
10. 대본·대사에 `{동무}`(데리고 다니는 동무 별명) 바꿔 넣기를 새로 만들지 — 만들지 않으면 script.md의 `{동무}`를 「네 동무」·「내 동무」로 바꿈.
11. jq2 보상으로 이야기 속 족제비(꼬마 족제비 little_ferret, 양품)를 줄지(world_pet_sources quest:jq2_tamer, 이미 있으면 동무 주먹밥 3) — 대본은 곰실이 데려가는 결말로 써 두었고, 주기로 하면 마지막 장면 두 줄만 바꾸면 됨.
