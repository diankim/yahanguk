# 다음 확장팩 — 「내 모습」(별채에 내 캐릭터) 기획

사용자 요청 2026-11-08. 배포 목표: 다음 주말(11/14~15). 구현할 때 CLAUDE.md와 이 문서를 함께 고친다.

## 정해진 것(사용자 결정 11/8)

- 직접 그린 머리는 별채·조사원 카드·채팅 얼굴(프로필 이미지)까지 쓸 수 있다.
- 의상 상자는 전으로 사고, 이미 있는 옷이 나오면 「옷감 조각」을 준다(조각을 모아 원하는 옷과 바꿈, 동무 정표처럼). 확률은 화면에 밝힌다.

- 그림 크기: 2등신 28×34칸(머리 가로 24칸 안팎·키의 약 2/3, 몸통 폭 9~10칸 — 머리 폭의 40% 안팎). 견본 scratchpad/avatar/chibi.png(생성기 chibi2.py). 검은 테 대신 짙은 갈색이 섞인 테.
- 옷 칸: 윗옷·아랫옷 둘 + 머리 장식 하나.

## 짜임(무엇을 어디에 만드나)

### 그림 — 겹쳐 그리는 종이 인형

- 층: 뒷머리 → 몸(피부색) → 아랫옷 → 윗옷 → 얼굴(눈·입) → 앞머리 → 머리 장식. 층마다 같은 칸 크기의 도트 판, 빈칸은 투명.
- 움직임: 서 있기·눈 감기·걷기(발만 바뀜) 세 장. 동무와 같은 방식(assets/js/housing/petsprite.js drawSprite)을 그대로 쓴다.
- 원본은 tools/avatar_art/(동무 tools/pet_art처럼 Python 그림 → 생성기가 assets/js/housing/avatar.js를 만듦). 옷·머리 하나가 한 줄 정의.
- 처음 들어갈 양(안): 피부 4 · 머리 모양 8(색 8) · 눈 6 · 입 6 · 윗옷 12·아랫옷 10(직업 기본 한 벌씩 포함) · 머리 장식 8.
- 「꼬마 동무는 귀여워야 한다」와 같은 기준: 큰 머리·2×2 눈·볼 홍조, 무섭거나 사실적인 얼굴은 쓰지 않는다. 새 그림은 미리보기를 보여 확인받고 넣는다.

### 직접 그린 머리

- 그림 액자 그림판(views/drawings.js openEditor)을 「머리」 크기로 연다. 칸 크기는 고른 그림 크기의 머리 부분(2등신이면 16×13 안팎).
- 몸 위에 겹칠 자리를 그림판에 흐린 밑그림으로 보여 준다(목 위치가 어긋나지 않게).
- 저장은 world_drawings에 size 'H'로(하루 장수·제보·숨기기·운영진 내리기 모두 액자와 같은 길). 내려진 그림은 프리셋 머리로 돌아간다.
- 채팅 얼굴: 프로필 이미지 고르기에 「내 모습 얼굴」을 더한다. world_chat_faces가 그림 글자(px, 16×13이면 208자)를 실어 보내고 화면이 캔버스로 그린다(이미 처음 보는 사람만 한 번 묻고 기억하는 구조라 요청은 늘지 않음).

### 서버(새 마이그레이션 하나)

- 표 world_avatars(owner_id, look jsonb {skin, hair, hair_color, eyes, mouth, head_drawing, top, bottom, acc}, home_on, updated_at) — RLS·직접 읽기 없음, 캐릭터 정리(world_character_purge)에 더함.
- 표 world_wardrobe(owner_id, look_key, got_at) — 가진 옷·장식. 옷 물품을 「열기」하면 여기로 옮겨지고 가방에서 빠진다(동무 바구니 world_pet_adopt와 같은 방식이라 가방이 안 막힘).
- 옷 물품: world_item_catalog category 'outfit'(검사 제약에 더함), equipment_traits {look_key, slot top|bottom|acc, grade}. 상점·제작·퀘스트·칭호 보상은 이 물품을 주면 되므로 기존 길을 그대로 쓴다. 거래는 물품 상태일 때만(얻는 길마다 tradeable).
- 함수: world_avatar_get(누구) · world_avatar_set(look) — 가진 것만 입힘 · world_outfit_open(물품) · world_outfit_box_open(상자 → 무작위, 겹치면 옷감 조각) · world_outfit_trade(조각 → 옷).
- 수치 한 곳: world_outfit_rules(상자 값·등급 확률·조각 교환 수) → gamedata → 화면 확률 표.
- 별채: world_housing_snapshot이 집주인(한 지붕이면 두 사람)의 look을 함께 실어 보냄 — 요청 추가 없음.
- 조사원 카드: world_character_card에 look을 더함.

### 화면

- 캐릭터 › 「내 모습」 칸(새 하위 탭): 미리보기 + 피부·머리·눈·입·윗옷·아랫옷·장식 고르기 + 「머리 그리기」 + 「별채에 세우기」 켜고 끄기.
- 별채: 내 캐릭터가 동무처럼 바닥을 걷고(housing.js walkable·tickPet을 함께 씀) 가끔 가구 앞에 멈춘다. 누르면 이름 말풍선.
- 조사원 카드: 문장 옆에 작은 내 모습.
- 상점: 의상 상자(확률 표 「?」), 옷감 조각 교환 창.
- 도움말 「내 모습」 항목.
