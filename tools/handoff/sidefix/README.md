# 인수인계 — 3.0 이전 보조 퀘스트 대본 손질 (2026-11-22)

받는 쪽: 대본을 다듬는 다른 도구(GPT 등). 보내는 쪽: Claude(야행국 저장소·운영 DB 담당).

## 1. 무엇을 하나
야행국(웹 텍스트 RPG)의 **보조 퀘스트 262편** 서술·대사를 고친다. 이 퀘스트들은 3.0(명등기) 전에 쓴 것이라, 3.0 때 사용자가 확정한 대본 기준(ref/RULES.md)에 못 미친다.
- 고치는 것: 문장(서술·대사)만.
- 그대로 둘 것: 장면 수·장면 이름·할 일·화자·물품/요괴/지역/인물 이름·줄거리·결말.
- 고치는 강도: examples/의 시범 두 파일 정도. 걸리는 줄을 고치고, 감정·반응·유대·까닭을 필요한 만큼 더한다. 장면 길이는 원문의 1.0~1.4배 안. 이미 맞는 줄은 억지로 바꾸지 않는다.

## 3. 사용자가 정한 것(꼭 따름)
- 3.0 뒤에 쓴 퀘스트(뒷이야기 ep_*, 연담 rg_*, 명등기 뒤 mde_*·mds_*, 3.4 직업 퀘스트)는 고치지 않는다 — 이미 기준에 맞다. 세력 가입·등급 장면도 고치지 않는다.
- 문수(정청 서리, 20대 남자)는 희수를 평소 「희수 서리님」, 흥분하면 일하는 중이라는 걸 잊고 「누님」이라 부른다.
- 문수의 직책은 정청 서리(설정집 쪽). 퀘스트에서 「봉인고 서리」처럼 나오면 「정청 서리인데 봉인고 서고 일을 맡아 내려가 있는」 쪽으로 맞춘다.
- 인물 성별(사용자 결정 11/20): 문수·월하·경현·서율·윤도한은 남자, 서하·희수·연서희·여울은 여자.
- 사용자가 다른 도구로 다듬은 대본은 문장은 그대로 받되, 대사 밖 설정(규칙·물품·처리·수치)이 기획서와 다르면 기획서를 따른다(그래서 설정을 바꾸지 말고, 바꿀 게 보이면 「제안」에 적는다).

## 4. 돌려줄 것
- 묶음마다 결과 파일 하나: `out/batch_NN.md`(원문 번호 그대로). 꼴은 RULES.md §5 — 원문과 같은 꼴에 장면마다 「고친 점」, 파일 끝에 「검사」·「제안」.
- 한 묶음을 끝내면 grep 검사 일곱 가지(RULES.md §5 끝)를 그 파일에 돌린 결과를 적는다.
- 확인하지 못한 것은 「제안」에 그대로 적는다. 다 보지 않은 묶음을 끝났다고 적지 않는다.

## 5. 받은 뒤 Claude가 하는 일(참고)
1. out 파일을 읽어 원문과 견준다 — 퀘스트·장면 수, 화자키, 할 일 줄, `{이름}`·`{직업:…}` 꼴이 그대로인지 기계로 검사.
2. 줄마다 기준 24를 다시 훑고, 「제안」은 사용자에게 묻는다.
3. 운영 데이터와 차이 7편을 맞춘다: cq110_bat_2·sq110_cangue_ghost·sq110_f_redmoon·sq110_returning_wave·sq110_s_yunpal·sq110_weeping_mirror·sq111_threshold_guard는 운영 DB에서 `{직업:…}` 안 혈기·여명·진법(·조련) 칸이 두 번 붙어 있다(src에는 한 번만). 고친 글에서는 한 번만 쓰면 되고, 이 중복은 Claude가 함께 정리한다.
4. 마이그레이션을 만들어 로컬 복제 DB에서 시험 → 사용자 승인 → 배포. 운영 DB에 쓰는 것은 Claude만 한다.
